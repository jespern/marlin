# Optional assets

`mk.pak` and `wo.pak` are the game data for the wipEout and Mario Kart 64
ports, which now live on the `console-ports` branch. Releases up to v0.2.1
download these files from `main/assets/` on first use, so they stay here until
those releases no longer matter. Nothing on `main` reads them.

See [the asset store](../docs/ASSETS.md) for how on-demand assets are verified
and cached.
