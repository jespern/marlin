>> what IS marlin??

marlin is a terminal AI agent harness: a daemon that owns your sessions + thin clients that attach to them. kill your terminal, the agent keeps working. reattach from your phone over ssh. it's like tmux and claude code had a baby and the baby was a fish.

  • one static binary — scp-and-run, no node_modules the size of Jupiter
  • daemon-native — sessions survive client death, reboots, your mood
  • append-only block log — the store is TRUTH, scrollback is a view
  • multi-model review councils — 4 LLMs argue about your crypto code so you don't have to
  • written in Zig — compiles before you finish blinking
