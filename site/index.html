>> what IS marlin??

marlin is a daemon-native terminal AI agent harness. The daemon owns structured sessions; the TUI and headless CLI are thin clients. Close a terminal and the turn keeps running. Reattach later—or from another terminal over SSH—and the transcript, status, approvals, and full tool results are still there.

  • one binary: no Node runtime, no Python environment, no terminal scraping
  • structured multiplexer: switch sessions without losing drafts, scroll position, or actionable state
  • append-only truth: context may compact; durable history and full tool output do not pretend they never happened
  • process-boundary extensions: managed MCP stdio servers, executable tools, hooks, and Markdown skills
  • durable child fan-out: a parent can delegate two to eight concurrent read-only jobs to inspectable children
  • real image input: local clipboard paste and remote-safe path upload stay durable and reach vision models
  • NOT a kitchen sink: marlin is a daily driver. a feature earns its place by surviving daily use, or it gets deleted. the default answer to a new surface is no
DEVELOPMENT PREVIEW Marlin is already self-hosting and useful for real work, but it is not a stable 1.0 product. The multiplexer and extension foundations are built; bounded concurrent child delegation is built, and M6 is turning those primitives into review councils. Config and protocol details may still move.

>> take it for a swim

$ curl -fsSL https://marlin.wtf/install.sh | sh
$ export OPENROUTER_API_KEY=...
$ marlin run "why is my build broken"
# ...the daemon keeps the structured session...
$ marlin             # attach the TUI
$ marlin ls          # short stable handles, including children
$ marlin attach 63df # any unique prefix (minimum four)

The installer downloads the matching tagged release for macOS or Linux on aarch64 or x86_64, verifies its SHA-256 checksum, and installs it in ~/.local/bin without sudo. Homebrew also works: brew install jespern/tap/marlin. Tracking main instead? Clone the repository and run zig build with Zig 0.16.0.

>> NOT shipped yet (honesty zone)

  • review councils: bounded fan-out exists, but named councils and reviewer synthesis are next—not marketing-present-tense
  • MCP streamable HTTP: stdio is managed and supported today; remote HTTP transport remains later
  • native remote transport: use SSH/mosh (or your tailnet) today; a raw TCP mode waits for a concrete trust boundary. marlin web exists as an opt-in, token-gated, localhost-only phone client—not a hosted product
  • workspace undo/isolation: snapshots, leases, worktrees, /land, and /discard remain one deliberately later track
  • kitchen sink surfaces: no messaging gateway, voice stack, embedded terminal emulator, or dashboard empire
